# src/pin.rs reads this file, and nothing else declares these versions.

# Bump BOTH lines together, never one alone. mlx-c is compiled against a
# specific mlx and both resolve the moving `opt` symlink at run time, so a

#
# The gate that enforces this is `linked_mlx_matches_the_pinned_pair`
# (crates/rmlx-mlx/src/pin_tests.rs). It reads the library dyld resolved for
# the running process and scans that metallib for the kernel family the pin
# exists to buy — a version match alone is not evidence, because bottle
# contents vary by build runner.
#
# Why these versions: docs/FFI.md -> "Pinned MLX / mlx-c pair".
# How to build them: docs/MLX_PAIR.md.
#
# Format: <formula> <version>, the Homebrew keg directory name. A Homebrew
# revision suffix (`0.6.0_4`) is part of the name: same upstream version,
# different build.
