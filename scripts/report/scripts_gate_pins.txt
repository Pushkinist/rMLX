# Accepted violations of the scripts/ rules: `<rule> <path> [<members>]`; a pin only shrinks.
#
# A pin accepts every violation of that rule in that file. Fix the file and delete its
# line: a pin whose file now passes fails the gate (`pin-stale`). A rule whose violation
# is a set pins the set (`exit-undeclared` the codes, `recall-missing` and `silenced` the modes, `lib-run`
# the sites, `dead-path` the tokens, `name` the hyphen and the root variables, `lib-shadow`
# the functions, `env-knob` the variables, `unguarded-array` the arrays); a rule whose violation is a measure pins the
# measure (`size` the line count, `heredoc` the lengths of the over-limit bodies, `twin` the
# matched lines of a pair written `<a>+<b>`, `binary-literal` the site count). A measure that
# grew fails its `-pin` rule; one that shrank asks for the pin to be lowered.
# Never pin a new file, a new member or a larger measure.
#
# pinnable: class purpose usage exit-undeclared caller recall-missing silenced lib-consumers lib-run shebang exec-bit dead-path set-mode name size heredoc twin lib-shadow binary-literal env-knob unguarded-array
